# PLAYLAB-FRONTEND

Site vitrine PLAYLAB — PC Gaming Academy.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Contenu statique (Phase 1 MVP)

## Démarrage

```bash
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## Pages MVP

- `/` Accueil
- `/formations` Catalogue
- `/formations/[slug]` Détail formation
- `/services` Services + formulaire (statique)
- `/a-propos` À propos
- `/contact` Contact (statique)

Design System : tokens orange `#FF8A00` / cyan `#00C8F5` (validé).
